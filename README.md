# 👋 Hey, I'm Dhruv Kumar

I build AI products, web apps and SaaS that hold up in production.

I've worked independently since December 2023. I've built 10+ websites and web applications for clients in India, Australia and New Zealand, plus my own SaaS, [ATS FastScan](https://atsfastscan.com/), which is live today.

I'm self-taught. No bootcamp. I learned by putting things online, watching what broke and fixing it. So I ship fast, plan for failure cases and stay around after launch.

## 🚀 What I've Built

### [ATS FastScan](https://atsfastscan.com/)

AI resume analysis SaaS, built with my co-founder Aaditya.

I built the product end to end: the Gemini analysis pipeline, login with Firebase, JWT verification, multi-tenant data isolation with Row Level Security on Supabase and PostgreSQL, usage limits and subscriptions, and Razorpay payments with webhook verification.

Launched on Product Hunt in February 2026.

### [AustralMach Engineering](https://australmach.com.au/)

Production website for an Australian manufacturer, with enquiry flows and spam protection.

### Purohit Khakhra House

### Hotel Website and Google Business Setup

The hotel now gets calls from Maps and visits on the site.

### Multi-Business AI Dashboard

Separate data per business, role-based access, automated invoicing and OpenAI features.

## 🧠 How I Build

Before I write code, I write a spec in Markdown.

It covers user roles, data boundaries, API contracts, auth flows and what happens when things fail.

Then I build with Cursor, Antigravity and Claude.

I use AI to move faster. I still own the design and review what ships.
