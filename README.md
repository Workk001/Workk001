## 🧠 How I Build

Before writing code, I write the system down.

I define:

- User roles and permissions
- Data boundaries
- API contracts
- Authentication flows
- Usage limits
- Failure cases

Then I build, test, ship and fix what breaks.

I use AI tools to move faster. I still own the architecture, decisions and what ultimately ships.
